# Самиторио v0.4

Клон Factorio на Python + pygame-ce. Процедурные текстуры с анимацией, конвейеры, вставщики, шахты, печи, сборщики, исследования, электричество, ночные волны врагов.

Что нового в 0.4:
- **Главное меню**: «Продолжить» / «Новая игра» (случайный сид!) / «Настройки» / «Выход».
- **Сохранения**: память слота `slot1`, автосохранение каждую игровую минуту и при выходе.
- **Меню паузы** (`ESC`): продолжить, сохранить, настройки, сохранить и в меню, выход на рабочий стол.
- **Настройки**: язык (EN/RU), звук, музыка, громкость эффектов, громкость музыки, FPS.
- **Локализация**: весь интерфейс переведён на русский и английский (предметы, технологии, HUD, меню).
- **Звук и музыка**: процедурный синтез (выстрелы, взрывы, добыча, стройка, волны и мягкий эмбиент-пэд) — без внешних файлов.

## Запуск
- Требуется Python 3.12+ (на 3.14 нужен **pygame-ce** — `python -m pip install pygame-ce`).
- Дважды кликнуть **RUN.bat** (сам установит pygame-ce) или вручную `python main.py`.

## Управление
- `WASD` — движение, `LMB` — копать/ставить, `RMB` — отмена в режиме строительства.
- `E` — инвентарь, `T` — исследования, `B` — режим строительства.
- В режиме строительства: `1-9` — выбор здания, `R` — поворот (конвейер/вставщик/шахта),
  `[` / `]` — смена рецепта сборщика, `LMB` — поставить (драг по ленточной линии).
- `ESC` — пауза / меню.

## Прогрессия
1. Копай руду, топи её в каменной печи (`B`, цифра `2`).
2. Сделай вручную красные колбы науки (шестерни + медь), изучи «Автоматику» (`T`).
3. Ставь шахты на залежи и конвейеры — ресурсы потекают сами.
4. Вставщики подают руду в печи, на выходе — пластины.
5. Сборщик делает колбы автоматически → логистика → сталь → турели → электричество.

## Модули
| Файл | Что делает |
|------|-----------|
| `main.py` | Игровой цикл, машина состояний (меню/игра/пауза/настройки), автосохранение |
| `menu.py` | Главное меню, пауза, экран настроек (мышь/клавиатура) |
| `lang.py` | Локализация EN/RU: HUD, инвентарь, исследования, меню, предметы, технологии |
| `settings.py` | Настройки в `saves/settings.json` (язык, звук, громкости) |
| `snd.py` | Процедурные звуки и музыка (синтез, без файлов) |
| `saveload.py` | Сохранения `saves/autosave.sz` / `slot1.sz` (zlib+json) |
| `core.py` | Все данные: предметы, рецепты, технологии, здания, направления |
| `tex.py` | Процедурные текстуры по координатам, руда-россыпи, валуны, анимация |
| `world.py` | Карта, биомы, руда, скалы, декор/деревья, загрязнение |
| `entities.py` | Конвейеры, вставщики, шахты, печи, лаборатории, турели |
| `power.py` | Электросеть: уголь, солнце, накопление |
| `combat.py` | Враги, снаряды, эволюция |
| `research.py` | Дерево технологий |
| `inventory.py` | Инвентарь, ручной крафт |
| `player.py` | Игрок (модель с анимацией ходьбы, столкновения) |
| `lighting.py` | Освещение/туман войны |
| `ui.py` | HUD (FPS), мини-карта (кэш), строительное меню |

## Тесты
- `smoke_test.py` — headless: логистика (шахта → лента → вставщик → печь → сборщик → исследование) + round-trip сохранение/загрузка.
- `ui_test.py` — headless: интерфейс (строительство, инвентарь, исследования).
- Запускать: `python smoke_test.py`, `python ui_test.py`.
